# Z03.89 No Diagnosis or Condition

> **Spark note:** This is an additional code, not a disorder. It records that the person **was evaluated** and found to have **no mental disorder or condition** (p. 1067). Use it to close an evaluation cleanly instead of forcing a residual diagnosis.

## When to use
- After a completed evaluation (intake, forensic, pre-employment, court-ordered, second opinion) finds no Section II disorder **and** no ch. 25 condition that warrants coding.
- Do not use it when a Z-code condition (e.g., relational problem, phase of life problem) is the focus. Code that instead.
- Do not use it to imply that an incomplete evaluation established the absence of a disorder or condition. An unspecified category requires evidence of a clinically significant mental-disorder presentation; incomplete information or the mere presence of symptoms does not by itself justify F99. Use a chapter-specific category when its requirements are supported, and document unresolved questions.

## Coding
| Code | Use |
|---|---|
| Z03.89 | Evaluated; no mental disorder or condition is present |

## Documentation cues (for client notes)
- Name the evaluation components (interview, MSE, screening instruments, collateral, records reviewed).
- State the conclusion: "No DSM-5-TR mental disorder or condition identified."
- Note the pertinent negatives (e.g., denies SI/HI; no mood, anxiety, psychotic or substance sx meeting threshold; functioning intact).
- If stressors were discussed but are not a clinical focus, say so to justify not using a Z code.
