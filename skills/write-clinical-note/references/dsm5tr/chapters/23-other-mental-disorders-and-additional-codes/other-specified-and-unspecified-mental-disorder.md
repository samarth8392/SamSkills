# Other Specified / Unspecified Mental Disorder (F99)

> **Spark note:** F99 is the broadest residual code in DSM-5-TR. It is for a presentation that clearly is a mental disorder but that **no** Section II category fits, including the chapter-level "other specified"/"unspecified" slots. Both versions share F99; only the written label differs. Reaching for F99 when, say, unspecified anxiety or depressive disorder would fit is the main misuse.

## Criteria at a glance
All four must hold (p. 1065):
1. The presentation is a mental disorder (symptoms → clinically significant distress or impairment).
2. Criteria are not met for any specific Section II mental disorder.
3. No other specified/unspecified category in Section II fits.
4. No other mental disorder diagnosis applies.

| | Other specified mental disorder | Unspecified mental disorder |
|---|---|---|
| Code | F99 | F99 |
| Reason recorded? | Yes: "other specified mental disorder" + specific reason | No; includes insufficient info (e.g., ED) |

## Coding
| Code | Recording |
|---|---|
| F99 | "Other specified mental disorder, [reason]" |
| F99 | "Unspecified mental disorder" |

## Clinical pearls
- If a medical etiology is established, use F06.8/F09 instead (medical code first).
- If the symptoms don't reach clinically significant distress/impairment, it's not a disorder; consider Z codes (ch. 25) or Z03.89.
- Re-evaluate when more history becomes available. A residual diagnosis does not automatically take the formal "(provisional)" modifier; that modifier has separate requirements in Section I.

## Differential diagnosis
- **Chapter-level residual categories** (e.g., unspecified mood disorder, F39, new in TR; unspecified anxiety disorder, F41.9): these come first whenever the symptom domain is identifiable.
- **Due-to-AMC residuals (F06.8/F09)**: physiological medical cause established.
- **Z03.89**: evaluated, and no disorder or condition is present.

## Documentation cues (for client notes)
- Describe the symptoms and the specific impairment (who/what/how often).
- State which disorders and chapter-level residual categories were considered and why each was ruled out.
- Other specified: give the reason in plain words (e.g., "mixed affective/behavioral symptoms not fitting any chapter's residual category").
- Unspecified: note what limited the evaluation (time, collateral unavailable, acute setting) and the plan to clarify.
