# Other Specified Personality Disorder (F60.89) & Unspecified Personality Disorder (F60.9)

> **Spark note:** Use when PD-type symptoms with distress/impairment predominate but no specific PD is fully met.
> "Other specified" = you state *why* (e.g., "mixed personality features"); "unspecified" = you don't, or there's
> not enough information yet. The specific reason or information limitation should remain visible in the record.

## Criteria at a glance (p. 980–981, 1033–1034)
- PD-characteristic symptoms causing clinically significant distress/impairment **predominate**, but full criteria for any
  specific PD are not met.
- Chapter introduction describes two OSPD situations:
  1. General PD criteria met + traits of several PDs present, but no single PD's criteria met (mixed personality features).
  2. General PD criteria met but the person's PD is not in DSM-5 (e.g., **passive-aggressive personality disorder**).
- **Unspecified:** clinician chooses not to specify the reason, incl. insufficient information for a more specific diagnosis.

## Coding
| Code | Use | Recording |
|---|---|---|
| F60.89 | Other specified personality disorder | "Other specified personality disorder (mixed personality features)" or "(passive-aggressive personality traits)" etc. |
| F60.9 | Unspecified personality disorder | "Unspecified personality disorder" — e.g., ED/brief assessment with insufficient history |

## Example presentations named in the text
- Mixed personality features (traits of several PDs, none fully met).
- A personality disorder not in DSM-5 classification — passive-aggressive PD.
- Insufficient information (unspecified).

## Clinical pearls
- Still requires general PD features (enduring, pervasive, early-onset, not better explained) for OSPD per the chapter intro.
- Prefer a specific PD if criteria are met; multiple specific PDs can be diagnosed together rather than defaulting to "mixed."
- Personality change from baseline due to a medical condition → F07.0, not OSPD.

## Documentation cues (for client notes)
These are assessment prompts, not observed findings. Record only assessed/reported evidence, attribute its source, and preserve uncertainty; an MSE list does not describe every person with the diagnosis.

- State which general PD criteria are met (pattern, pervasiveness, onset, impairment) and which specific PD traits are present
  using the actual assessed features and counts rather than inserting a hypothetical client profile.
- For OSPD, write the specific reason in the diagnosis line.
- For UPD, note what information is missing (collateral, longitudinal history) and the plan to clarify.
- Document rule-outs: mood/anxiety episode, substance, medical condition, psychotic disorder.
