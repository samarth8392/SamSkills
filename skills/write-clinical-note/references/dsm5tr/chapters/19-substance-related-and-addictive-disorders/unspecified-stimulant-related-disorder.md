# Unspecified Stimulant-Related Disorder

> **Spark note:** Residual category. The code still splits by drug: **F15.99** amphetamine-type or other stimulant; **F14.99** cocaine.

## Criteria at a glance
- Symptoms characteristic of a stimulant-related disorder; clinically significant distress/impairment; predominate.
- Full criteria not met for any specific stimulant-related disorder or any other disorder in the class.

## Coding
| Code | Use |
|---|---|
| F15.99 | Unspecified amphetamine-type substance or other stimulant–related disorder |
| F14.99 | Unspecified cocaine-related disorder |

## Documentation cues (for client notes)
- Name the stimulant (determines the code); describe the symptoms and impairment.
- List which specific disorders were considered and which thresholds were missed.
- Plan for re-assessment.
