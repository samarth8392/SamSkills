# Other (or Unknown) Substance Intoxication

> **Spark note:** Unknown intoxication is an attribution requiring evidence and exclusions, not a name for any unexplained altered state. The source acknowledges the difficulty of proving a characteristic syndrome when the agent is unidentified. (pp. 890–893)
## Criteria at a glance
**A:** Recent exposure to an unclassified or unidentified substance produces a reversible characteristic syndrome. **B:** Clinically problematic CNS-related behavioral/psychological changes develop during/soon after use. **C:** No better medical, mental or other-intoxicant explanation. Unlike the named class syndromes, no fixed physical-sign count is specified; clinical judgment and corroborating exposure/course are needed. (pp. 890–893)

## Specifiers & severity
No separate symptom-count severity scale is specified for this acute syndrome. **With perceptual disturbances** requires preserved reality testing during hallucinations, or illusions, without delirium. Loss of insight calls for a psychotic-disorder assessment; impaired attention/awareness calls for delirium assessment. (pp. 890–893)

## Coding
Source-edition codes (pp. 890–893):

| Comorbid same-class use disorder | Code |
|---|---|
| Mild | F19.120 |
| Moderate/severe | F19.220 |
| None | F19.920 |

With perceptual disturbances, use F19.122 / F19.222 / F19.922 for mild / moderate-severe / no use disorder.

Use the combined code rather than a separate stand-alone use-disorder code; name the specific substance if known.

## Diagnostic features & clinical pearls
Ask about reproducible episodes after the same product/source and local clusters of similar presentations. Name the agent when known. Route and metabolism govern onset, which can range from minutes to delayed toxicity; acute reversibility does not preclude lasting injury. Routine testing can miss novel agents. (pp. 891–892)

## Prevalence · Development & course · Risk & prognostic factors
Prevalence is unknown; course and risk vary by substance. Refer to [other/unknown use disorder](other-or-unknown-substance-use-disorder.md) for shared context. (pp. 891–892)

## Suicide risk
Not specifically addressed in this intoxication section.

## Functional consequences
Work/relationship disruption, hazardous behavior, accidents and overdose vary with agent and severity. (p. 892)

## Differential diagnosis
Use without a qualifying syndrome; a familiar agent sold under a novel name; predominant induced psychiatric disorder; medical/neurological mimics; and withdrawal from another agent. Lethargy, for example, is not specific to intoxication. (pp. 892–893)

## Comorbidity
Other SUDs, conduct disorder and antisocial personality disorder can coexist. (p. 893)

## Documentation cues (for client notes)
- State evidence of exposure, what remains unknown, chronology, observed syndrome and reproducibility/collateral.
- Document medical/neurological and other drug exclusions, reality testing, attention and actual functional effects.
- Revisit class attribution when testing/history clarifies identity; determine use disorder separately.
