# Clinical-Attention Code Quick Table

> **Spark note:** This lookup includes T, R, and E codes as well as Z codes. Repeated codes preserve distinct source labels; choose by the documented condition and encounter purpose, not the number alone.

## Usage notes
All codes reproduce the supplied DSM-5-TR edition. This is a study table, not verification of a later billing code set. T-code treatment-phase rules differ in their source wording between suicidal behavior and abuse/neglect; see the linked topic notes. Conditions in this chapter are not mental disorders. (pp. 1085–1087)

## Documentation cues (for client notes)
Record the specific condition, source of evidence, current/history or encounter status where relevant, and why it affects the visit or management. Do not infer a condition from a code search result.
