# Watercolor PPT Backgrounds

## Purpose

Create presentation-ready watercolor illustrations that remain visually consistent
across an entire slide deck even when the subject matter changes substantially.

The user should normally need to specify only the subject, scene, concept, and
desired placement. Apply the visual system in this skill automatically unless the
user explicitly overrides part of it.

The output should feel like a hand-painted scientific notebook or editorial
illustration, not a digital infographic, technology advertisement, stock image,
or polished vector graphic.

---

# Core Visual Language

## Medium

Always render the image as:

- soft, hand-painted watercolor
- visible textured watercolor paper
- translucent layered washes
- subtle pigment pooling
- irregular feathered edges
- natural variation in pigment density
- slightly imperfect hand-painted forms

The image must visibly read as watercolor.

Do not create:

- crisp vector shapes
- hard digital outlines
- flat digital fills
- photorealistic rendering
- glossy 3D rendering
- polished product-render aesthetics
- thick opaque acrylic or oil-paint texture

Edges should remain soft and organic.

---

# Background

Default background:

- warm cream / off-white watercolor paper
- approximately `#F7F5F0`

The paper texture should remain visible throughout the image.

Avoid:

- black backgrounds
- dark backgrounds
- dramatic storm skies
- deep saturated gradient backgrounds
- futuristic blue-black technology environments
- screen-like gradients
- vignette effects

The overall image should remain visually light.

---

# Color Palette

Use a restrained muted watercolor palette.

Primary colors:

- dusty / muted teal: `#3E6E6B`
- soft pale blue
- warm sage green
- warm amber / ochre
- soft terracotta

Optional secondary accents:

- dusty rose
- pale violet-grey
- muted blue-grey

Secondary accents should be used sparingly.

Colors should appear as watercolor washes rather than precise digital swatches.

Avoid:

- neon colors
- bright primary colors
- highly saturated cyan
- highly saturated purple
- glossy metallic colors
- pure black fills

Use dark tones only when necessary for subtle watercolor contrast.

---

# Overall Mood

The default mood is:

- calm
- thoughtful
- collaborative
- scientific
- editorial
- approachable
- quiet
- human
- reflective

The image should resemble an illustration from:

- a scientific notebook
- an editorial science article
- a thoughtful research essay
- a hand-painted educational book

It should not resemble:

- a corporate infographic
- a startup landing page
- a technology advertisement
- cyberpunk art
- a stock-photo composition
- a futuristic AI poster

---

# Aspect Ratio and Slide Use

Default output:

- horizontal
- 16:9
- suitable for PowerPoint or Keynote

Compose explicitly for slide use.

Unless the user asks for a full-frame illustration, preserve enough negative space
for slide text.

Do not assume that every image should fill the frame with objects.

---

# Composition Rules

## Default Slide-Background Composition

When the user does not specify otherwise:

- place the illustrated subject in one corner or along one edge
- use approximately one-third to one-half of the frame for the illustration
- leave the remaining area as open cream watercolor paper
- avoid centering the primary subject
- keep the illustration visually grounded
- leave clean space suitable for title and body text

Preferred placements:

- lower-left
- lower-right
- right edge
- left edge
- lower third

If the user specifies a location, follow it.

Examples:

- "bottom-right" → compact illustration in the bottom-right
- "left side" → subject anchored left with open space on the right
- "upper-right" → subject positioned there while preserving readable empty space
- "centered" → center only when explicitly requested

---

# Negative Space

Negative space is a core feature of this style.

For slide-background images:

- large empty cream regions are desirable
- avoid decorative filler
- avoid unnecessary floating objects
- do not populate empty areas merely to balance the frame
- preserve visual calm

When the user says the image is meant to stand alone rather than support overlaid
text, the subject may occupy most of the frame.

---

# Full-Frame Illustration Mode

Use full-frame mode only when:

- explicitly requested
- the user says no text space is required
- the illustration itself is the slide
- the user asks for a centered standalone concept

In full-frame mode:

- use most of the vertical and horizontal image area
- maintain some breathing room at the edges
- preserve watercolor-paper visibility
- avoid clutter

---

# Human Figures

When depicting people:

- use loose watercolor figures
- keep facial detail minimal
- prefer simplified editorial anatomy
- use gentle rounded forms
- use muted single-tone clothing or silhouette washes
- avoid photorealistic faces
- avoid fashion-detail emphasis
- avoid stock-photo posing

If faces are unnecessary, omit facial features entirely.

For group scenes:

- use varied muted colors
- give figures approximately equal visual weight unless hierarchy is requested
- imply conversation through body orientation and hand gestures

---

# Scientist Figures

Scientists should feel approachable and human.

Possible visual cues:

- simple white or pale lab coat
- notebook
- laptop
- papers
- charts
- subtle scientific objects
- desk or collaborative table

Do not overuse laboratory glassware unless explicitly relevant to the subject.

Scientific context should be suggested rather than overloaded with symbols.

---

# Robot Character

When the user asks for the recurring friendly robot, use this default design:

- small scale
- rounded head
- rounded rectangular or boxy torso
- simple rounded limbs
- friendly proportions
- dusty teal and pale blue-grey watercolor washes
- soft glowing dot-like eyes when a face is requested
- one small warm amber detail or chest panel
- optional single antenna or head light
- watercolor bleed at every edge

The robot should feel more like:

- a picture-book character
- a soft educational companion
- a friendly research assistant

It should not feel like:

- industrial machinery
- military hardware
- humanoid android
- polished commercial robot
- chrome or metal product render

Avoid:

- sharp joints
- hard metal reflections
- exposed complex machinery
- aggressive posture
- glowing particle bodies
- neon circuitry

---

# Robot Variants

## Faceless Robot Silhouette

When requested:

- remove facial features
- use a rounded head and boxy torso
- allow subtle watercolor patterning inside the silhouette
- botanical, root-like, or circuit-like branching motifs may be used
- keep the silhouette soft and organic

## Robot at Computer

When the robot is shown coding:

- place it at a simple desk
- use a loosely painted laptop or terminal window
- suggest code using horizontal watercolor brushstrokes
- do not generate readable code unless explicitly requested
- use muted teal, amber, sage, and pale grey bands
- avoid literal glowing screens

---

# Human + Robot Scenes

Human and robot should normally have equal conceptual importance.

Avoid making the robot visually dominant through:

- brighter glow
- larger scale
- stronger contrast
- dramatic lighting

For collaborative scenes:

- orient both figures toward a shared task
- use relaxed poses
- place shared scientific content between them
- imply cooperation rather than replacement of the human

Useful shared motifs include:

- DNA
- papers
- plots
- laptop
- network diagram
- notebook
- abstract molecular structure

# Scientific Motifs

Scientific content should be painted as simplified watercolor motifs rather than
precise diagrams unless precision is explicitly required.

Common motifs include:

- DNA double helix
- cells
- nucleus and organelles
- molecules
- node-and-line networks
- scatter plots
- bar charts
- heatmaps
- chromosomes
- sequence-like bands
- biological pathways
- gene-expression matrices
- books
- papers
- notebooks
- computers
- simple laboratory objects

Keep motifs visually legible but stylistically loose.

---

# Charts and Data

When a chart is decorative or conceptual:

- use watercolor dots, bars, or brushstrokes
- preserve recognizable chart structure
- avoid labels
- avoid readable numbers
- avoid crisp axes
- avoid exact spreadsheet styling

When showing a heatmap:

- use a small grid of soft-edged watercolor squares
- vary muted colors gently
- avoid strong outlines
- avoid saturated rainbow palettes

When showing code:

- use horizontal colored brushstrokes
- suggest syntax highlighting
- do not generate literal readable code unless the user asks for it

---

# Floating Scientific Motifs

When showing a shared concept floating between figures:

- keep it modest in scale
- use soft watercolor marks
- use only a few elements
- avoid holographic glow
- avoid digital projection effects

Examples:

- DNA helix
- simple molecule
- small node network
- abstract data marks

These should look painted into the scene, not projected by technology.

---

# Circular Vignettes

When the user asks for circular specialty motifs around a central scene:

- use pale translucent watercolor circles
- keep borders diffuse
- use one dominant muted tone per vignette
- connect them with thin curving watercolor threads
- avoid sharp infographic connectors
- maintain generous spacing between circles

Possible vignette subjects:

- DNA
- cell
- molecule
- test tube
- heatmap
- network
- chromosome
- protein
- plant
- ecological motif

The overall result must still read as a unified watercolor illustration rather
than an infographic.

---

# Connections and Lines

Connector lines should be:

- thin
- hand-painted
- gently curved
- imperfect
- faint
- watercolor-like

Avoid:

- straight digital arrows
- crisp connector lines
- thick diagram edges
- arrowheads unless essential
- geometric network styling

# Tables and Collaboration Scenes

For group-collaboration scenes:

- use a round or softly painted wooden table
- slight overhead or three-quarter overhead perspective works well
- use five or six simplified figures when appropriate
- give each figure a distinct muted tone
- use body posture to imply discussion

Possible table objects:

- laptop
- papers
- scatter plot
- bar chart
- books
- notebook
- small potted plant

Only include laboratory glassware if relevant to the user's request.

# Objects and Furniture

Furniture should remain simple.

Use:

- light wooden desk

- simple chair
- books
- notebook

The scene should remain editorial rather than architectural.

# Plants and Botanical Elements

# Subject Interpretation

The user may provide a short prompt such as:

"Draw me a watercolor-theme slide image showing a scientist comparing three
genomic workflows."

Interpret this as:

1. Preserve this skill's watercolor visual system.
2. Translate the scientific concept into a simple visual scene.
3. Choose an appropriate editorial composition.
4. Preserve negative space unless the user requests a full-frame illustration.
5. Avoid adding literal labels unless requested.
6. Use scientific motifs only where they improve comprehension.
7. Keep the image stylistically consistent with previous images made using this
   skill.

---

# Composition Keywords

Interpret common placement phrases as follows.

## "bottom-right"

- compact subject
- lower-right corner
- subject faces inward when possible
- leave left and upper regions empty

## "bottom-left"

- compact subject
- lower-left corner
- subject faces inward
- leave right and upper regions empty

## "right side"

- illustration occupies roughly right third
- left side remains mostly empty

## "left side"

- illustration occupies roughly left third
- right side remains mostly empty

## "centered"

- center the core subject
- maintain breathing room
- do not reserve a dominant text column unless requested

## "full frame"

- subject may occupy most of the image
- no deliberate large text region
- preserve light background and watercolor softness

## "small"

Treat "small" strictly.

If the user asks for a subject to occupy no more than one-quarter of the frame,
keep it genuinely compact.

# Slide-Deck Consistency

When producing multiple images for the same deck, maintain:

- the same cream paper tone
- the same watercolor texture
- the same muted palette
- similar pigment density
- consistent softness of edges
- recurring proportions for robot characters
- recurring visual treatment for scientific motifs
- similar level of detail
- similar visual weight

Do not reinvent the artistic style between slides.

Variation should come from:

- subject
- composition
- orientation
- scientific content
- storytelling

not from changing the rendering style.

# Prompt Expansion Template

Internally expand user requests into the following structure before generating the
image:

STYLE:
Soft hand-painted watercolor on visible warm cream watercolor paper. Translucent
pigment washes, feathered irregular edges, subtle pigment pooling, no hard vector
outlines, no photorealism, no glossy rendering. Muted palette centered on dusty
teal, pale blue, sage green, ochre, terracotta, with optional dusty rose or
violet-grey accents.

MOOD:
Calm, scientific, editorial, thoughtful, human, collaborative.

FORMAT:
Horizontal 16:9 presentation illustration.

COMPOSITION:
Follow the user's requested placement. If unspecified, anchor the main scene to
one side or lower corner and preserve generous cream negative space for slide
text.

SUBJECT:
Insert the user's requested scientific, conceptual, narrative, or metaphorical
scene.

DETAIL:
Simplify complex scientific information into a small number of recognizable
watercolor motifs. Avoid unnecessary labels and clutter.

AVOID:
Dark backgrounds, neon colors, photorealism, hard vector linework, corporate
infographic styling, glossy 3D, cyberpunk lighting, drop shadows, literal
holograms, and excessive decoration.

# Priority Rules

When instructions conflict, use this order:

1. Explicit instructions in the current user request
2. Requested scientific meaning
3. Requested composition and placement
4. This skill's visual system
5. Default slide-background composition

Never ignore a user's explicit instruction in order to preserve a default from
this skill.

---

# Output Behavior

When the user requests an image:

- generate the image directly
- do not ask for confirmation when the request is sufficiently specific
- preserve the watercolor style defined here
- do not add explanatory text to the image unless requested
- prefer one coherent scene over a collection of disconnected icons
- ensure the composition is usable on a presentation slide

The primary objective is a coherent family of presentation illustrations that
look as though they were painted by the same watercolor illustrator for the same
scientific slide deck.
